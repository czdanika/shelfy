A Shelfy telepítése

A Shelfy egyetlen Docker-konténerként fut. Válaszd ki a rendszeredet, állíts be néhány értéket, és másold ki a fájlt, amit ez az oldal elkészít neked.

1Válaszd ki a rendszeredet

Olyan eszköz kell, amelyen Docker-konténer futtatható: NAS, Raspberry Pi, vagy bármilyen linuxos, windowsos vagy macOS-es gép. A kép amd64 és arm64 változatban készül, a konvertáló eszközökkel együtt.

Telepítsd az App Centerből a Docker Managert (vagy a Portainert). Hozz létre új projektet / stacket compose fájlból, és illeszd be a lenti fájlt. Portainerben: Stacks → Add stack → Web editor.

Nyisd meg a Container Managert (DSM 7.2 vagy újabb) → Projekt → Létrehozás. Útvonalnak az adatmappát add meg, válaszd a docker-compose.yml létrehozása lehetőséget, és illeszd be a lenti fájlt.

Nyisd meg a Container Stationt → Applications → Create, add neki a shelfy nevet, és illeszd be a lenti fájlt a YAML-szerkesztőbe.

Telepítsd a Community Applicationsből a Docker Compose Manager bővítményt, adj hozzá új stacket, és illeszd be a lenti fájlt. Bővítmény nélkül használd a docker run parancsot terminálban.

Telepítsd a Dockert (curl -fsSL https://get.docker.com | sh), mentsd a lenti fájlt docker-compose.yml néven egy üres mappába, és ott futtasd: docker compose up -d.

2Állítsd be

Ide kerül minden, amit a Shelfy tárol. Ez az egyetlen mappa, amit menteni kell.
A Shelfy az eszközöd ezen a portján lesz elérhető.
Mindenki választhat saját nyelvet.
A napló időbélyegeihez.
Hagyd üresen, ha a könyvek maradhatnak az adatmappában.
Csak ha „permission denied” hibát látsz: a mappák tulajdonosa (SSH-n: id <felhasználónév>).

Előbb hozd létre a mappákat, hogy a saját felhasználódé legyenek:

Utána illeszd be a fájlt oda, ahová a rendszered kéri (lásd az 1. lépést), és indítsd el.


  




4Nyisd meg a Shelfyt

  
Ha a konténer fut, nyisd meg ezt a címet egy böngészőben az otthoni hálózaton, és hozd létre az adminisztrátori fiókot:

  
http://<nas-ip>:18200

  
A <nas-ip> helyére az eszközöd címét írd.




5Első beállítások

  
  1. Beállítások (bal oldali menü): alapnyelv, az online források és sorrendjük, valamint az e-mail (SMTP) fiók a Kindle-re küldéshez. Az oldalon lépésről lépésre Gmail-útmutató is van.
  2. Adminisztráció → Felhasználók: vedd fel a családtagokat.
  3. Tölts fel néhány könyvet, vagy másold be őket a figyelt mappába.
  4. A Saját fiók oldalon add meg a Kindle e-mail címedet, vagy kapcsold össze az Amazon-fiókodat, hogy e-mail nélkül küldhess.

  
A kézikönyv leírja, mit tud a Shelfy, ha már fut.




Elérés kívülről

  
A Shelfy sima HTTP-n válaszol a portján. Ha otthonon kívülről is el szeretnéd érni, tedd HTTPS-es fordított proxy (Nginx Proxy Manager, Caddy, Traefik) vagy alagút mögé, például Cloudflare Tunnel vagy Tailscale.

  
Cloudflare mögött egy feltöltés nem lehet nagyobb a csomagod korlátjánál (az ingyenes csomagon 100 MB). A nagyobb fájlokat az otthoni hálózatról töltsd fel, vagy másold a figyelt mappába.

  
A régi Kindle-böngészők sok modern HTTPS-oldalt nem tudnak megnyitni. Otthon a Kindle-ön a helyi címet használd: http://<nas-ip>:18200.

Változatok
A könyvfájlok külön megosztásban – például ha a könyvek a Konyvek megosztásba kerüljenek, amit amúgy is mentesz:


    volumes:
      - /Volume1/DockerAppsData/shelfy:/data
      - /Volume1/Konyvek/Shelfy:/data/library          # könyvfájlok és borítók (Szerző/Cím (id)/…)


Figyelt mappa nélkül – hagyd ki az /ingest kötetet és az INGEST_DIR sort.


A legegyszerűbb változat – Docker által kezelt kötet NAS-mappa helyett (ezt a NAS fájlkezelőjéből nehezebb elérni):


services:
  shelfy:
    image: ghcr.io/czdanika/shelfy:latest
    restart: unless-stopped
    ports: ["18200:8080"]
    volumes:
      - shelfy-data:/data
volumes:
  shelfy-data:


Első adminisztrátor a stackből – add meg az ADMIN_USER és ADMIN_PASSWORD változót (legalább 8 karakter). Csak addig számít, amíg nincs felhasználó.

Frissítés
  • Portainer: nyisd meg a stacket, és válaszd az Update the stack gombot Re-pull image opcióval (vagy Pull and redeploy).
  • Parancssor: docker compose pull && docker compose up -d

Elfelejtett jelszó
Egy felhasználó jelszavát az admin az Adminisztráció → Felhasználók oldalon állíthatja vissza. Ha az admin a sajátját felejtette el, a szerveren futtasd ezt (a webes felületről nem érhető el):


docker exec -it shelfy python -m app.reset_password            # felhasználók listája
docker exec -it shelfy python -m app.reset_password daniel     # új jelszó beállítása
docker exec -it shelfy python -m app.reset_password daniel --admin   # …és adminná tétel


Utána a felhasználó minden eszközről kijelentkezik.
Mentés, visszaállítás, költözés
Az adatbázis kicsi, a könyvfájlok a LIBRARY_DIR mappában vannak. Az Adminisztráció → Mentés oldalon:


  • letölthetsz adatbázis-mentést (adatok, felhasználók, polcok, beállítások) vagy teljes mentést, ami a könyvfájlokat is tartalmazza;
  • bekapcsolhatod a napi automatikus adatbázis-mentést a DATA_DIR/backups mappába (megadod, hányat őrizzen meg);
  • visszaállíthatsz feltöltött vagy a szerveren tárolt mentésből. Előtte a jelenlegi állapotról biztonsági mentés készül.


Nagy könyvtárnál a könyvmappát a NAS saját mentőeszközeivel érdemes menteni, Shelfyvel csak az adatbázist. Költözéskor: másold át a könyvmappát, indítsd el az új Shelfyt, állítsd vissza az adatbázis-mentést, majd futtasd a Könyvtár ellenőrzése feladatot. Parancssorból:


docker exec shelfy python -m app.backup create                          # csak adatbázis, a DATA_DIR/backups mappába
docker exec shelfy python -m app.backup create --full -o /data/full.zip # könyvfájlokkal együtt
docker exec shelfy python -m app.backup check                           # hiányzó fájlú könyvek

# parancssori visszaállítás: előbb állítsd le a Shelfyt, aztán egy egyszeri konténerrel
docker compose stop shelfy
docker compose run --rm shelfy python -m app.backup restore /data/backups/<fájl>.zip
docker compose start shelfy
