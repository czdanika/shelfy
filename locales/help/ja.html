はじめに

Shelfy は家庭用の電子書籍ライブラリです。本をアップロードすると、Shelfy がファイルを検査してメタデータをオンラインで補完します。その後は家族の誰でも本を閲覧・ダウンロードしたり、Kindle に送信したりできます。

  1. アップロード – 本をアップロードページにドラッグします。
  2. 確認 – 検査が終わったら、提案されたメタデータを確認して本をライブラリに追加します。
  3. Kindle – マイアカウントで Kindle のメールアドレスを入力すれば、ワンクリックで本を送れます。

本のアップロード

  • アップロードページで、点線の枠にファイルをドロップするか「パソコンから選択」をクリックします。複数のファイルを一度にアップロードできます。
  • 対応形式：EPUB、MOBI、AZW3、AZW、PRC、PDF、FB2、CBZ、CBR、DOCX、ODT、RTF、TXT、DJVU。
  • 監視フォルダー： インストール時に設定していれば、そこ（サブフォルダーを含む）にコピーした電子書籍が自動で取り込まれます。それ以外のファイル（画像など）はそのまま残り、取り込んだ本はフォルダーから移動されます。
  • アップロードには、管理者が付与するアップロード権限が必要です。

検査と確認

アップロードしたファイルは自動で検査されます。検査ログに結果が順番に表示されます：

  • 形式、完全性 – ファイルは拡張子どおりの形式で、壊れていないか。
  • 同一ファイル、重複 – まったく同じファイル、または同じタイトルと著者の本がすでにライブラリにあるか。
  • 埋め込みメタデータ、表紙 – ファイルから読み取れた情報と、埋め込み表紙の大きさ。
  • オンライン検索 – Moly.hu、Google Books、Open Library の候補と一致率。
  • カテゴリ – タグと内容紹介に基づく提案。

確認ページでは：

  • 候補から正しいもの（または「ファイルのメタデータのみ」）を選びます。どれも合わなければ、再検索でタイトル、著者、ISBN を指定して絞り込みます。
  • 提案されたメタデータは追加の前に編集できます。表紙は埋め込みのものとオンラインのものから選べます。
  • カテゴリはタグとして本に追加されます。クリックでオン・オフを切り替えます。
  • すでに持っている本なら、「… 形式として追加」で既存の本に新しい形式としてファイルを追加できます。
  • 確認待ちが複数ある場合は上部に一覧が表示され、「追加して次へ」で次の本にすぐ進めます。
  • 検査待ちのすべて承認は、一致度の高い本をまとめて追加します（重複は除外）。

多くの本を取り込むときは、設定 → 確実に一致した場合は自動で追加をオンにしてください。一致率 85% 以上で重複でない本は自動で追加されます。

ライブラリの閲覧

  • 検索 – 上部の欄でタイトル、著者、シリーズ、タグ、ISBN を検索します。
  • 表示 – 左のメニュー：すべて、最近追加、人気、高評価、読書状況別。一覧の下：著者、シリーズ、タグ、出版社、言語、形式、評価。
  • 並べ替え – 本の上のバーで指定します（追加日、タイトル、著者、発行年、シリーズ、評価）。選択は記憶されます。
  • グリッドとリスト – 右上のアイコンで切り替えます。リストでは表紙の横に主な情報と内容紹介の冒頭が表示されます。
  • サイズ – スライダーで表紙の大きさ（1 行に並ぶ冊数）を調整し、その横で 1 ページの件数を選びます。
  • クイックメニュー – グリッド表示で表紙にカーソルを合わせると、ダウンロード、Kindle に送信、編集、本棚に追加ができます。
  • 本棚 – 本のページから好きな本を自分の本棚（例：「休暇用」）に入れられます。本棚は左のメニューに表示されます。

本のページ

  • ダウンロード – 既存のどの形式でも可能です。MOBI、AZW3、EPUB がなければ、ダウンロード時に Shelfy が作成します。
  • 変換 – 本に新しい形式を恒久的に追加します（編集権限が必要）。
  • 編集 – 表紙を含むすべての項目。
  • オンラインのメタデータ – オンラインの情報元を改めて検索し、現在の値とオンラインの値を並べて、反映する項目にチェックを入れます。
  • 読書状況 – 未読、読書中、読了。ユーザーごとに別々です。
  • 履歴 – 誰がいつ本をダウンロード・送信・編集したか（編集者が閲覧可能）。

Kindle

メールで送信

  1. マイアカウントで Kindle のメールアドレス(…@kindle.com)を入力します。
  2. Amazon アカウントで、送信元アドレスを承認済み送信者に追加します(コンテンツと端末の管理 → 設定 → パーソナル・ドキュメント設定)。
  3. 本のページかクイックメニューで Kindle に送信 を選びます。

管理者が共有の送信アカウントを設定しますが、各自がマイアカウントで自分のアカウントを設定することもできます（Gmail のヘルプがあります）。本が MOBI か AZW3 しかない場合、Amazon は現在 EPUB しか受け付けないため、Shelfy が先に EPUB を作成します。最大サイズは 50 MB です。

Kindle のブラウザーからダウンロード

Kindle で開くと、Shelfy は電子ペーパーに適したシンプルな Kindle 表示に自動で切り替わります。設定で新しい Kindle(AZW3)か古い Kindle（MOBI のみ）を選びます。古い Kindle では、多くの HTTPS サイトを開けないため、ローカルネットワークのアドレス(http://…)を使ってください。

スマートフォンで

ブラウザーのメニューから「ホーム画面に追加」を選ぶと、Shelfy が専用アイコン付きの独立したアプリとして開きます。

マイアカウント

  • 表示名、表示言語、Kindle のメールアドレス、パスワードの変更。
  • 個人のメール送信(SMTP) – 空欄の場合は共有アカウントが使われます。
  • 自分のアクティビティ – 自分のダウンロード、送信、アップロード。
  • 言語と外観（自動 / ライト / ダーク）は上部のバーで設定できます。

管理者向け

  • ユーザー – 役割：管理者（すべてにアクセス可）、編集者、読者。権限（アップロード、編集、ダウンロード、削除）は個別にも設定できます。個人のメール設定もここで割り当てられます。
  • 設定 – 共有メール送信(SMTP)、テストメール、自動追加、ライブラリの統計、システムの状態。
  • 言語 – すべての文言を翻訳できます。各言語の翻訳率を確認し、新しい言語を追加できます。画面から編集した翻訳はアップデート後も保持されます。
  • アクティビティログ – 重要な出来事をすべて日時付きで記録：アップロード、追加、送信（失敗を含む）、ダウンロード、ログイン、設定変更。種類、ユーザー、期間で絞り込んだり、エラーだけを表示したりできます。

パスワードを忘れたとき

管理者はユーザーページで利用者のパスワードをリセットできます。管理者が自分のパスワードを忘れた場合は、サーバーで次を実行します：

docker exec -it shelfy python -m app.reset_password <ユーザー名>

バックアップ、復元、移行

Shelfy は 2 つの部分からなります：

  • データベース(データフォルダーの shelfy.db): 本のメタデータ、ユーザー、本棚、読書状況、アクティビティログ、設定 – 数 MB の小さなファイル。
  • ライブラリフォルダー：著者/タイトル (id)/ フォルダー内の本のファイルと表紙 – 大部分の容量。データベースはこれらのファイルを参照します。

この 2 つでライブラリ全体になります。管理者設定 → バックアップでは：

  • データベースのみ – 小さな ZIP。ライブラリフォルダーが NAS 上にあり、NAS 自体のバックアップ（別ボリュームやクラウドなど）で保護されているなら十分です。
  • 完全バックアップ – データベースとすべての本のファイル・表紙を 1 つの ZIP に（100 冊で約 100 MB）。Shelfy 全体を一度に移行できます。
  • 自動バックアップ – データフォルダー内の backups フォルダーに毎日データベースをバックアップします。保持日数を選べます。

別のマシンへの移行

  1. 古い Shelfy で完全バックアップをダウンロードします。
  2. 新しい場所で Shelfy を起動し、一時的な管理者アカウントを作成します。
  3. 管理者設定 → バックアップ → 復元で ZIP をアップロードします。データベースと本のファイルが元に戻り、以前のユーザーは自分のパスワードでログインできます。

または、ライブラリフォルダーを NAS 上の新しい場所にコピーし、データベースのバックアップだけを復元することもできます。その後ライブラリの確認で不足しているファイルを確認できます。

大きなライブラリはコマンドラインで

docker exec shelfy python -m app.backup create --full      # backups フォルダーに完全バックアップ
docker exec shelfy python -m app.backup check              # 不足ファイルを確認
docker compose stop shelfy
docker compose run --rm shelfy python -m app.backup restore /data/backups/<ファイル>.zip
docker compose start shelfy

バックアップにはパスワードのハッシュと暗号化キーが含まれます。安全な場所に保管してください。復元の前に、Shelfy は必ず現在の状態を保存します(before-restore-…zip)。

バックグラウンドタスク

時間のかかる処理（アップロードの検査、変換、Kindle への送信、バックアップ、復元）はタスクページで確認できます。誰が開始したか、状態、実行時間、結果が表示されます。サイドバーには実行中のタスク数が表示されます。管理者はここからライブラリの確認（不足ファイル）と重複の検索を開始できます。タスクは 14 日間一覧に残ります。

よくある質問

本が Kindle に届きません。
アクティビティログ（管理者）または自分のアクティビティを確認してください。送信に失敗していれば理由が表示されます。成功している場合は、送信元アドレスが Amazon で承認されていない可能性があります。
アップロード時に間違ったメタデータが入りました。
本のページのオンラインのメタデータで再検索するか、編集で手動で修正してください。
表紙がありません。
情報不足の表示に、表紙や内容紹介のない本が一覧されます。オンラインのメタデータ、または編集（表紙のアップロード）で対応できます。
