快速入門

Shelfy 是家用電子書庫：上傳圖書後，Shelfy 會檢查檔案並線上補全中繼資料，之後家裡的每個人都可以瀏覽、下載圖書或傳送到 Kindle。

  1. 上傳 – 把圖書拖到上傳頁面。
  2. 審閱 – 檢查完成後，核對建議的中繼資料，再把圖書加入書庫。
  3. Kindle – 在我的帳戶中填寫 Kindle 電子郵件地址，即可一鍵傳送圖書。

上傳圖書

  • 在上傳頁面，把檔案拖進虛線框，或點選「從電腦中選擇」。可以一次上傳多個檔案。
  • 支援的格式：EPUB、MOBI、AZW3、AZW、PRC、PDF、FB2、CBZ、CBR、DOCX、ODT、RTF、TXT、DJVU。
  • 監視資料夾：如果安裝時已設定，複製到該資料夾（含子資料夾）的電子書會被自動匯入。其他檔案（圖片等）不受影響；匯入後的圖書會被移出該資料夾。
  • 上傳需要上傳許可權，由管理員授予。

檢查與審閱

每個上傳的檔案都會自動檢查。檢查日誌會逐步顯示結果：

  • 格式、完整性 – 檔案是否與副檔名一致，是否完好？
  • 相同檔案、重複 – 書庫中是否已有完全相同的檔案，或書名和作者相同的圖書？
  • 內嵌中繼資料、封面 – 從檔案中讀取到了哪些資訊，內嵌封面有多大。
  • 線上查詢 – 已啟用的線上來源所提供的結果及匹配度（見設定 → 線上來源）。
  • 分類 – 根據標籤和簡介給出的建議。

在審閱頁面：

  • 從匹配結果中選出正確的一項（或「僅檔案中繼資料」）。如果都不對，在重新搜尋中用書名、作者或 ISBN 縮小範圍。
  • 新增前可以編輯建議的中繼資料。封面可在內嵌封面和線上封面之間選擇。
  • 分類會作為標籤新增到圖書，點選即可開關。
  • 如果已有這本書，「作為 … 格式新增」會把檔案作為新格式附加到現有圖書。
  • 如果有多個上傳等待審閱，它們都會列在頂部，「新增並繼續下一本」會直接跳到下一本。
  • 佇列中的全部批准會一次性新增所有匹配良好的圖書（跳過重複）。

匯入大量圖書時，請開啟設定 → 匹配可靠時自動新增：匹配度不低於 85% 且不重複的圖書會自動新增。

瀏覽書庫

  • 搜尋 – 頂部搜尋框可搜尋書名、作者、系列、標籤和 ISBN。
  • 檢視 – 左側選單：全部、最近新增、熱門、評分最高、按閱讀狀態；在瀏覽下：作者、系列、標籤、出版社、語言、格式、評分。
  • 排序 – 在圖書上方的欄中選擇（新增時間、書名、作者、出版時間、系列、評分）。你的選擇會被記住。
  • 格狀和列表 – 用右上角的圖示切換。列表會在封面旁顯示主要資訊和簡介開頭。
  • 大小 – 滑塊調整封面大小（也就是每行顯示幾本書）;旁邊可以選擇每頁顯示多少本。
  • 快捷選單 – 在格狀檢視中把滑鼠移到封面上，即可下載、傳送到 Kindle、編輯或加入書架。
  • 書架 – 在圖書頁面把任意圖書放進個人書架（例如「假期」）;你的書架會顯示在左側選單中。

圖書頁面

  • 下載 – 可下載任何已有格式。如果缺少 MOBI、AZW3 或 EPUB,Shelfy 會在下載時生成。
  • 轉換 – 為圖書永久新增一種新格式（需要編輯許可權）。
  • 編輯 – 所有欄位，包括封面。
  • 線上中繼資料 – 重新搜尋線上來源；當前值和線上值並排顯示，勾選要採用的項即可。
  • 閱讀狀態 – 未讀、在讀、已讀；每個使用者各自獨立。
  • 歷史記錄 – 誰在何時下載、傳送或編輯了這本書（編輯可見）。

在瀏覽器中閱讀

在書籍頁面點按閱讀，書會直接在瀏覽器中開啟——電腦、平板或手機皆可。Shelfy 會為每位使用者記住閱讀位置：按鈕會變成附百分比的繼續閱讀，在另一台裝置上也能從同一位置接著讀。

  • EPUB 直接開啟。MOBI、AZW3 等格式在第一次開啟時會轉換為 EPUB（數秒鐘，可在任務中查看）。PDF 會在瀏覽器內建的 PDF 檢視器中開啟。
  • 閱讀需要下載權限；未登入的訪客無法閱讀。

翻頁

  • 點按或點擊頁面右側往後翻，點按左側約三分之一處往前翻——和電子書閱讀器一樣。
  • 點按頂部區域可顯示或隱藏上下工具列，只留下內文。
  • 也可以左右滑動，或使用鍵盤的方向鍵、空白鍵和 Page Up/Down。
  • 底部的滑桿可跳到書中任何位置；≡ 按鈕開啟目錄。

文字設定（Aa）

  • 背景：淺色、護眼或深色。
  • 字級、字型（與書中一致、Literata、Georgia、特別易讀的 Atkinson Hyperlegible，或簡潔的無襯線字型）、行距、邊界。
  • 對齊（左右對齊或靠左對齊）、斷字開／關。
  • 版面：寬螢幕時（如橫放的平板）雙欄或一律單欄；翻頁或連續捲動。

設定會依裝置分別儲存，因此手機和平板可以有不同的外觀。

閱讀進度

頁面下方的一行顯示目前位置。點按可在以下內容間切換：百分比、本章剩餘時間、全書剩餘時間、本章內頁碼。Shelfy 會學習你的閱讀速度，讀幾頁後時間估算就會變得準確。讀到結尾時，這本書會標示為已讀。

書籤、畫線、筆記

  • 書籤：頂部的書籤圖示標記目前頁面（再點按一次即移除）。
  • 畫線：選取文字（觸控螢幕上：長按後拖曳選取控點），然後選擇顏色。也可以在此加入筆記。
  • 點按已有的畫線可更改顏色、編輯筆記或刪除。
  • ≡ 面板在不同分頁中列出書籤和畫線；點按即可跳轉。

書籤、畫線和筆記儲存在伺服器上你的帳號中，因此在所有裝置上都看得到。

在平板和手機上，建議把 Shelfy 加入主畫面（見Kindle → 在手機上）：這樣閱讀器會以全螢幕開啟，沒有瀏覽器的工具列——就像電子書 App 一樣。閱讀時需要能連線到 Shelfy。

Kindle

透過郵件傳送

  1. 在我的帳戶中填寫 Kindle 電子郵件地址(…@kindle.com)。
  2. 在 Amazon 帳戶中，把發件地址新增到已認可的發件人(管理我的內容和裝置 → 偏好設定 → 個人文件設定)。
  3. 在圖書頁面或快捷選單中點選傳送到 Kindle。

管理員會設定一個共享傳送帳戶，但每個人也可以在「我的帳戶」中新增自己的帳戶（那裡有 Gmail 設定幫助）。如果一本書只有 MOBI 或 AZW3 格式，Shelfy 會先生成 EPUB，因為 Amazon 現在只接受 EPUB。最大檔案大小為 50 MB。

從 Kindle 瀏覽器下載

在 Kindle 上開啟時，Shelfy 會自動顯示適合墨水屏的簡潔 Kindle 檢視。在設定中選擇較新的 Kindle(AZW3)或舊款 Kindle（僅 MOBI）。舊款 Kindle 請使用區域網地址(http://…)，因為舊瀏覽器無法開啟很多 HTTPS 網站。

在手機上

在手機和平板上，左側選單會收起：用左上角的 ☰ 按鈕開啟（外觀、語言和說明也在其中）。在瀏覽器選單中選擇「加入主畫面」後，Shelfy 會以自己的圖示作為獨立 App 開啟——在 iPhone 和 iPad 的 Safari 中：分享 → 加入主畫面。在手機和平板上，Shelfy 也會在小視窗中主動提示；之後可在 ☰ 選單的「安裝為 App」中找到。

我的帳戶

  • 顯示名稱、介面語言、Kindle 電子郵件地址、修改密碼。
  • 個人郵件傳送(SMTP)– 留空則使用共享帳戶。
  • 我的活動 – 你自己的下載、傳送和上傳記錄。
  • 語言和外觀（自動 / 淺色 / 深色）可在頂部欄中設定；在手機和平板上位於 ☰ 選單中。

管理員須知

  • 使用者 – 角色：管理員（完全訪問）、編輯、讀者；許可權（上傳、編輯、下載、刪除）也可以逐項設定。還可以在這裡為某人設定個人郵件。
  • 設定 – 左側選單中的獨立項目；詳見設定一節。
  • 語言 – 所有文字都可翻譯；可以檢視各語言的完成度並新增新語言。在介面中編輯的翻譯在更新後依然保留。
  • 活動日誌 – 所有重要事件及其時間：上傳、新增、傳送（包括失敗）、下載、登入、設定更改。可按型別、使用者和時間段篩選，或只顯示錯誤。

忘記密碼

管理員可以在「使用者」頁面重置使用者密碼。如果管理員忘記了自己的密碼，請在伺服器上執行：

docker exec -it shelfy python -m app.reset_password <使用者名稱>

設定

給管理員：左側選單中的設定。變更會立即生效，不需重新啟動。

一般

  • 預設語言 – 訪客和新使用者的介面語言；分類標籤也會以此語言加到書籍上。每個人仍可選擇自己的語言。
  • 線上中繼資料查詢 – 上傳時和在書籍頁面是否查詢線上來源。
  • 監視匯入資料夾 – 關閉後暫停監視，例如在整理資料夾時。（資料夾本身在安裝時指定。）
  • 匹配可靠時自動新增 – 匹配度至少 85% 且不是重複的書，不需審核即可加入書庫。

存取

允許免登入瀏覽 – 沒有帳號的訪客也可以瀏覽書庫、搜尋並開啟書籍頁面。下載、閱讀、傳送到 Kindle、書架以及任何修改仍需登入。

線上來源

Shelfy 在哪些資料庫中查找書籍，以及依什麼優先順序：

  • Google Books – 全球、多語言；簡介和封面。對中文書通常是最好的來源。
  • Open Library – 免費的全球書目；適合較舊的書和英文書。
  • Moly.hu（匈牙利）、DNB（德國）、BnF（法國）、Biblioteka Narodowa（波蘭）、NDL（日本） – 各國的國家圖書館或書目庫，適合在該國出版的書。

勾選要使用的來源，並用箭頭調整順序。Shelfy 會同時查詢所有來源，並依匹配度排序結果；如果兩個結果差不多好，清單中較前面的來源優先。建議設定按鈕會套用適合預設語言的清單。

沒有自己的金鑰時，Google Books 使用一個很小的共享配額，經常用完（檢查報告中顯示「HTTP 429」）。在 Google Cloud 主控台免費申請一個 Google Books API 金鑰即可解決；金鑰會加密儲存。

郵件

用於傳送到 Kindle 的共享郵件帳號（SMTP），附測試郵件功能。

備份、還原、遷移

Shelfy 由兩部分組成：

  • 資料庫(資料目錄中的 shelfy.db):圖書中繼資料、使用者、書架、閱讀狀態、活動日誌、設定 – 很小，只有幾 MB;
  • 書庫資料夾：作者/書名 (id)/ 資料夾中的圖書檔案和封面 – 佔大部分空間。資料庫指向這些檔案。

兩者合起來才是完整的書庫。在管理 → 備份中：

  • 僅資料庫 – 一個小 ZIP。如果書庫資料夾在 NAS 上，且 NAS 自身的備份（如備份到其他儲存磁碟區或雲端）已覆蓋它，這就夠了。
  • 完整備份 – 資料庫 + 所有圖書檔案和封面，打包成一個 ZIP（100 本書約 100 MB）。可一次遷移整個 Shelfy。
  • 自動備份 – 每天把資料庫備份到資料目錄中的 backups 資料夾；可選擇保留多少天。

遷移到另一臺裝置

  1. 在舊的 Shelfy 中下載完整備份。
  2. 在新位置啟動 Shelfy，並建立一個臨時管理員帳戶。
  3. 管理 → 備份 → 還原：上傳 ZIP。資料庫和圖書檔案會還原到位，原來的使用者可以用自己的密碼登入。

也可以把書庫資料夾複製到 NAS 上的新位置，然後只還原資料庫備份。之後檢查書庫會列出缺少的檔案。

大型書庫請使用命令列

docker exec shelfy python -m app.backup create --full      # 完整備份到 backups 資料夾
docker exec shelfy python -m app.backup check              # 查詢缺少的檔案
docker compose stop shelfy
docker compose run --rm shelfy python -m app.backup restore /data/backups/<檔案>.zip
docker compose start shelfy

備份包含密碼雜湊和加密金鑰，請妥善保管。還原前，Shelfy 總會先儲存當前狀態(before-restore-…zip)。

背景任務

較長的操作（檢查上傳、轉換、傳送到 Kindle、備份、還原）可以在任務頁面檢視：誰啟動的、當前狀態、執行時長和結果。側邊欄會顯示正在執行的任務數。管理員可以在這裡啟動書庫檢查（查詢缺少的檔案）和重複項搜尋。任務會在列表中保留 14 天。

常見問題

圖書沒有到達我的 Kindle。
檢視活動日誌（管理員）或我的活動：如果傳送失敗，那裡會顯示原因。如果傳送成功，很可能是發件地址未在 Amazon 中認可。
上傳時採用了錯誤的中繼資料。
在圖書頁面用線上中繼資料重新搜尋，或用編輯手動修改。
缺少封面。
資訊不全檢視會列出沒有封面或簡介的圖書；可以用線上中繼資料或編輯（上傳封面）解決。
書在閱讀器中打不開。
EPUB 和 PDF 以外的格式需要先轉換——如果轉換失敗，閱讀器會提示，但仍可下載這本書。原因可在任務頁面查看。
在平板上點按頁面不會翻頁。
在捲動模式下，點按只會顯示／隱藏工具列——請在 Aa 中切換為翻頁。點按連結或選取文字時也不會翻頁。
