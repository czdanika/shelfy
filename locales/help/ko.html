시작하기

Shelfy는 가정용 전자책 서재입니다. 책을 업로드하면 Shelfy가 파일을 검사하고 메타데이터를 온라인에서 보완합니다. 그다음에는 가족 누구나 책을 둘러보고, 다운로드하거나 Kindle로 보낼 수 있습니다.

  1. 업로드 – 책을 업로드 페이지로 끌어다 놓으세요.
  2. 검토 – 검사가 끝나면 제안된 메타데이터를 확인하고 책을 서재에 추가하세요.
  3. Kindle – 내 계정에서 Kindle 이메일 주소를 입력하면 클릭 한 번으로 책을 보낼 수 있습니다.

책 업로드

  • 업로드 페이지에서 점선 상자에 파일을 놓거나 “컴퓨터에서 선택”을 누르세요. 여러 파일을 한 번에 올릴 수 있습니다.
  • 지원 형식: EPUB, MOBI, AZW3, AZW, PRC, PDF, FB2, CBZ, CBR, DOCX, ODT, RTF, TXT, DJVU.
  • 감시 폴더: 설치할 때 설정했다면, 그곳(하위 폴더 포함)에 복사한 전자책을 자동으로 가져옵니다. 다른 파일(이미지 등)은 그대로 두고, 가져온 책은 폴더에서 옮깁니다.
  • 업로드하려면 관리자가 주는 업로드 권한이 필요합니다.

검사와 검토

업로드한 파일은 모두 자동으로 검사됩니다. 검사 기록에 결과가 단계별로 나옵니다:

  • 형식, 무결성 – 파일이 확장자대로의 형식인지, 손상되지 않았는지.
  • 동일한 파일, 중복 – 똑같은 파일이나 같은 제목·저자의 책이 이미 서재에 있는지.
  • 포함된 메타데이터, 표지 – 파일에서 읽어 낸 정보와 포함된 표지의 크기.
  • 온라인 검색 – 켜 둔 온라인 출처의 검색 결과와 일치율(설정 → 온라인 출처 참고).
  • 분류 – 태그와 소개를 바탕으로 한 제안.

검토 페이지에서:

  • 일치 항목에서 맞는 것을 고르세요(또는 “파일 메타데이터만”). 맞는 것이 없으면 다시 검색에서 제목, 저자, ISBN으로 좁혀 보세요.
  • 제안된 메타데이터는 추가하기 전에 고칠 수 있습니다. 표지는 포함된 것과 온라인 것 중에서 고르세요.
  • 분류는 책에 태그로 추가됩니다. 클릭해서 켜고 끌 수 있습니다.
  • 이미 가진 책이라면 “… 형식으로 추가”로 기존 책에 새 형식으로 파일을 붙입니다.
  • 검토를 기다리는 업로드가 여러 개면 위쪽에 모두 나오고, “추가하고 다음”으로 바로 다음 책으로 넘어갑니다.
  • 대기열의 모두 승인은 잘 일치하는 책을 한꺼번에 추가합니다(중복은 건너뜀).

많은 책을 가져올 때는 설정 → 확실히 일치하면 자동으로 추가를 켜세요. 일치율이 85% 이상이고 중복이 아닌 책은 저절로 추가됩니다.

서재 둘러보기

  • 검색 – 위쪽 입력란은 제목, 저자, 시리즈, 태그, ISBN을 검색합니다.
  • 보기 – 왼쪽 메뉴: 모두, 최근 추가, 인기, 높은 평점, 읽기 상태별. 찾아보기 아래: 저자, 시리즈, 태그, 출판사, 언어, 형식, 평점.
  • 정렬 – 책 위의 막대에서 선택합니다(추가일, 제목, 저자, 출간, 시리즈, 평점). 선택은 기억됩니다.
  • 격자와 목록 – 오른쪽 위 아이콘으로 바꿉니다. 목록은 표지 옆에 주요 정보와 소개의 앞부분을 보여 줍니다.
  • 크기 – 슬라이더로 표지 크기(한 줄에 들어가는 책 수)를 정하고, 옆에서 페이지당 책 수를 고릅니다.
  • 빠른 메뉴 – 격자 보기에서 표지 위에 마우스를 올리면 다운로드, Kindle로 보내기, 편집, 책장에 추가를 할 수 있습니다.
  • 책장 – 책 페이지에서 어떤 책이든 개인 책장(예: “휴가”)에 넣을 수 있습니다. 책장은 왼쪽 메뉴에 나옵니다.

책 페이지

  • 다운로드 – 있는 형식이면 무엇이든. MOBI, AZW3, EPUB이 없으면 다운로드할 때 Shelfy가 만듭니다.
  • 변환 – 책에 새 형식을 영구적으로 추가합니다(편집 권한 필요).
  • 편집 – 표지를 포함한 모든 항목.
  • 온라인 메타데이터 – 온라인 출처를 새로 검색합니다. 현재 값과 온라인 값을 나란히 보고 가져올 항목을 선택합니다.
  • 읽기 상태 – 안 읽음, 읽는 중, 다 읽음. 사용자마다 따로 저장됩니다.
  • 기록 – 누가 언제 책을 다운로드·발송·편집했는지(편집자에게 보임).

브라우저에서 읽기

책 페이지에서 읽기를 누르면 책이 바로 브라우저에서 열립니다(컴퓨터, 태블릿, 휴대폰). Shelfy는 사용자마다 읽던 위치를 기억합니다. 버튼이 퍼센트와 함께 이어 읽기로 바뀌고, 다른 기기에서도 같은 위치부터 이어서 읽을 수 있습니다.

  • EPUB은 바로 열립니다. MOBI, AZW3 등 다른 형식은 처음 열 때 EPUB으로 변환됩니다(몇 초 걸리며 작업에서 확인 가능). PDF는 브라우저의 PDF 뷰어에서 열립니다.
  • 읽으려면 다운로드 권한이 필요합니다. 로그인하지 않은 손님은 읽을 수 없습니다.

페이지 넘기기

  • 페이지 오른쪽을 탭하거나 클릭하면 다음 페이지로, 왼쪽 약 3분의 1을 누르면 이전 페이지로 갑니다. 전자책 단말기와 같은 방식입니다.
  • 위쪽 띠를 탭하면 위아래 막대가 나타나거나 숨겨져 본문만 남습니다.
  • 왼쪽/오른쪽으로 스와이프하거나 키보드의 화살표, 스페이스, Page Up/Down으로도 넘길 수 있습니다.
  • 아래쪽 슬라이더로 책의 어느 위치로든 이동할 수 있고, ≡ 버튼은 목차를 엽니다.

텍스트 설정 (Aa)

  • 배경: 밝게, 세피아, 어둡게.
  • 글자 크기, 글꼴(책 그대로, Literata, Georgia, 특히 읽기 쉬운 Atkinson Hyperlegible, 단순한 고딕), 줄 간격, 여백.
  • 정렬(양쪽 맞춤 또는 왼쪽 맞춤), 하이픈 넣기 켜기/끄기.
  • 레이아웃: 화면이 넓으면(예: 가로로 둔 태블릿) 두 단 또는 항상 한 단, 페이지 또는 연속 스크롤.

설정은 기기마다 따로 저장되므로 휴대폰과 태블릿을 다르게 설정할 수 있습니다.

진행 상황

페이지 아래 줄에 현재 위치가 표시됩니다. 탭하면 퍼센트, 장의 남은 시간, 책의 남은 시간, 장 안의 페이지가 차례로 바뀝니다. Shelfy가 읽는 속도를 학습하므로 몇 페이지를 읽고 나면 남은 시간이 정확해집니다. 끝까지 읽으면 책이 다 읽음으로 표시됩니다.

북마크, 하이라이트, 메모

  • 북마크: 위쪽의 북마크 아이콘으로 현재 페이지를 표시합니다(다시 탭하면 해제).
  • 하이라이트: 텍스트를 선택하고(터치스크린에서는 길게 누른 뒤 손잡이를 끌기) 색을 고릅니다. 여기서 메모도 추가할 수 있습니다.
  • 기존 하이라이트를 탭하면 색 변경, 메모 수정, 삭제를 할 수 있습니다.
  • ≡ 패널의 별도 탭에 북마크와 하이라이트가 나열되며, 탭하면 그 위치로 이동합니다.

북마크, 하이라이트, 메모는 서버의 내 계정에 저장되므로 모든 기기에서 볼 수 있습니다.

태블릿과 휴대폰에서는 Shelfy를 홈 화면에 추가해 두면 좋습니다(Kindle → 휴대폰에서 참고). 그러면 리더가 브라우저 막대 없이 전체 화면으로 열려 전자책 앱처럼 쓸 수 있습니다. 읽으려면 Shelfy에 연결되어 있어야 합니다.

Kindle

이메일로 보내기

  1. 내 계정에서 Kindle 이메일 주소(…@kindle.com)를 입력하세요.
  2. Amazon 계정에서 발신 주소를 승인된 발신자 목록에 추가하세요(콘텐츠 및 기기 관리 → 환경 설정 → 개인 문서 설정).
  3. 책 페이지나 빠른 메뉴에서 Kindle로 보내기를 누르세요.

관리자가 공용 발송 계정을 설정하지만, 각자 내 계정에서 자신의 계정을 추가할 수도 있습니다(Gmail 도움말 있음). 책이 MOBI나 AZW3로만 있으면 Amazon이 이제 EPUB만 받기 때문에 Shelfy가 먼저 EPUB을 만듭니다. 최대 크기는 50MB입니다.

Kindle 브라우저에서 다운로드

Kindle에서 열면 Shelfy가 전자잉크에 맞춘 간단한 Kindle 보기로 자동 전환됩니다. 설정에서 신형(AZW3) 또는 구형 Kindle(MOBI만)을 고르세요. 구형 Kindle에서는 오래된 브라우저가 많은 HTTPS 사이트를 열지 못하므로 로컬 네트워크 주소(http://…)를 사용하세요.

휴대폰에서

휴대폰과 태블릿에서는 왼쪽 메뉴가 숨겨지며, 왼쪽 위의 ☰ 버튼으로 엽니다(화면 모드, 언어, 도움말도 이 안에 있습니다). 브라우저 메뉴에서 “홈 화면에 추가”를 하면 Shelfy가 자체 아이콘을 가진 별도 앱처럼 열립니다. iPhone과 iPad의 Safari에서는 공유 → 홈 화면에 추가입니다. 휴대폰과 태블릿에서는 Shelfy가 작은 창으로 직접 안내하며, 나중에는 ☰ 메뉴의 “앱으로 설치”에서 찾을 수 있습니다.

내 계정

  • 표시 이름, 인터페이스 언어, Kindle 이메일 주소, 비밀번호 변경.
  • 개인 이메일 발송(SMTP) – 비워 두면 공용 계정을 사용합니다.
  • 내 활동 – 내가 한 다운로드, 발송, 업로드.
  • 언어와 화면 모드(자동 / 밝게 / 어둡게)는 위쪽 막대에서 정합니다. 휴대폰과 태블릿에서는 ☰ 메뉴에 있습니다.

관리자용

  • 사용자 – 역할: 관리자(전체 접근), 편집자, 독자. 권한(업로드, 편집, 다운로드, 삭제)은 하나씩 설정할 수도 있습니다. 여기서 개인 이메일 설정을 줄 수도 있습니다.
  • 설정 – 왼쪽 메뉴의 별도 항목입니다. 자세한 내용은 설정을 참고하세요.
  • 언어 – 모든 문구를 번역할 수 있습니다. 언어별 완성도를 보고 새 언어를 추가하세요. 화면에서 고친 번역은 업데이트 후에도 유지됩니다.
  • 활동 기록 – 중요한 이벤트를 모두 시간과 함께 기록: 업로드, 추가, 발송(실패 포함), 다운로드, 로그인, 설정 변경. 종류, 사용자, 기간으로 거르거나 오류만 볼 수 있습니다.
  • 책 숨기기 – 책 페이지의 숨기기 버튼을 누르면 관리자만 그 책을 볼 수 있습니다. 다른 사용자와 손님에게는 목록, 검색, 둘러보기, Kindle 화면 어디에도 보이지 않으며 페이지와 파일도 열 수 없습니다. 관리자에게는 표시가 붙어 보이고 왼쪽 메뉴의 숨긴 책에도 나열되며, 보이게 하기로 되돌릴 수 있습니다.
  • 보관 – 책 페이지의 보관하기를 누르면 서재 목록, 둘러보기, 개수에서 빠지지만 왼쪽 메뉴의 보관됨에서 모두가 계속 볼 수 있습니다(간직하고 싶은 오래된 책 등). 보관 해제로 되돌릴 수 있습니다. 숨긴 책과 달리 보관한 책은 누구나 열 수 있습니다.

비밀번호를 잊었을 때

관리자는 사용자 페이지에서 사용자의 비밀번호를 재설정할 수 있습니다. 관리자가 자기 비밀번호를 잊었다면 서버에서 다음을 실행하세요:

docker exec -it shelfy python -m app.reset_password <사용자이름>

설정

관리자용: 왼쪽 메뉴의 설정 항목입니다. 변경 사항은 다시 시작하지 않아도 바로 적용됩니다.

일반

  • 기본 언어 – 방문자와 새 사용자의 화면 언어이며, 카테고리 태그도 이 언어로 책에 붙습니다. 각자 자신의 언어를 고를 수 있습니다.
  • 온라인 메타데이터 검색 – 업로드할 때와 책 페이지에서 온라인 출처를 검색할지 여부.
  • 가져오기 폴더 감시 – 끄면 감시가 일시 중지됩니다(예: 폴더를 정리하는 동안). 폴더 자체는 설치할 때 지정합니다.
  • 확실히 일치하면 자동으로 추가 – 일치율이 85% 이상이고 중복이 아닌 책은 검토 없이 서재에 추가됩니다.

접근

로그인 없이 둘러보기 허용 – 계정이 없는 방문자도 서재를 둘러보고, 검색하고, 책 페이지를 열 수 있습니다. 다운로드, 읽기, Kindle로 보내기, 책장, 모든 변경에는 여전히 로그인이 필요합니다.

온라인 출처

Shelfy가 어떤 데이터베이스에서, 어떤 우선순위로 책을 찾을지:

  • Google Books – 전 세계, 다국어. 설명과 표지. 한국어 책에는 보통 가장 좋은 출처입니다.
  • Open Library – 무료 세계 목록. 오래된 책과 영어 책에 좋습니다.
  • Moly.hu(헝가리), DNB(독일), BnF(프랑스), Biblioteka Narodowa(폴란드), NDL(일본) – 각 나라에서 출판된 책을 위한 출처.

사용할 출처에 체크하고 화살표로 순서를 정하세요. Shelfy는 모든 출처를 동시에 검색하고 일치도에 따라 결과를 정렬합니다. 두 결과가 거의 비슷하면 목록에서 위에 있는 출처가 우선합니다. 추천 설정 버튼은 기본 언어에 맞는 목록을 설정합니다.

자체 키가 없으면 Google Books는 작은 공용 할당량을 쓰기 때문에 자주 소진됩니다(검사 보고서에 “HTTP 429”). Google Cloud 콘솔에서 받는 무료 Google Books API 키로 해결할 수 있으며, 키는 암호화되어 저장됩니다.

이메일

Kindle로 보낼 때 쓰는 공용 이메일 계정(SMTP)과 테스트 이메일.

백업, 복원, 이전

Shelfy는 두 부분으로 되어 있습니다:

  • 데이터베이스(데이터 폴더의 shelfy.db): 책 메타데이터, 사용자, 책장, 읽기 상태, 활동 기록, 설정 – 몇 MB의 작은 파일.
  • 서재 폴더: 저자/제목 (id)/ 폴더의 책 파일과 표지 – 대부분의 용량. 데이터베이스가 이 파일들을 가리킵니다.

둘을 합쳐야 서재 전체가 됩니다. 관리자 → 백업에서:

  • 데이터베이스만 – 작은 ZIP. 서재 폴더가 NAS에 있고 NAS 자체 백업(다른 볼륨이나 클라우드 등)이 이를 다룬다면 충분합니다.
  • 전체 백업 – 데이터베이스 + 모든 책 파일과 표지를 ZIP 하나에(책 100권이 약 100MB). Shelfy 전체를 한 번에 옮깁니다.
  • 자동 백업 – 데이터 폴더의 backups 폴더에 매일 데이터베이스를 백업합니다. 보관 일수를 고르세요.

다른 장비로 옮기기

  1. 기존 Shelfy에서 전체 백업을 다운로드합니다.
  2. 새 위치에서 Shelfy를 시작하고 임시 관리자 계정을 만듭니다.
  3. 관리자 → 백업 → 복원에서 ZIP을 업로드합니다. 데이터베이스와 책 파일이 제자리를 찾고, 기존 사용자는 자기 비밀번호로 로그인할 수 있습니다.

또는 서재 폴더를 NAS의 새 위치로 복사한 다음 데이터베이스 백업만 복원해도 됩니다. 그 뒤 서재 확인이 빠진 파일을 보여 줍니다.

큰 서재는 명령줄에서

docker exec shelfy python -m app.backup create --full      # backups 폴더에 전체 백업
docker exec shelfy python -m app.backup check              # 빠진 파일 찾기
docker compose stop shelfy
docker compose run --rm shelfy python -m app.backup restore /data/backups/<파일>.zip
docker compose start shelfy

백업에는 비밀번호 해시와 암호화 키가 들어 있으니 안전한 곳에 보관하세요. 복원하기 전에 Shelfy는 항상 현재 상태를 먼저 저장합니다(before-restore-…zip).

백그라운드 작업

시간이 걸리는 작업(업로드 검사, 변환, Kindle로 보내기, 백업, 복원)은 작업 페이지에서 볼 수 있습니다. 누가 시작했는지, 상태, 실행 시간, 결과가 나옵니다. 사이드바에는 실행 중인 작업 수가 표시됩니다. 관리자는 여기서 서재 확인(빠진 파일)과 중복 찾기를 시작할 수 있습니다. 작업은 14일 동안 목록에 남습니다.

자주 묻는 질문

책이 Kindle에 도착하지 않아요.
활동 기록(관리자)이나 내 활동을 확인하세요. 발송이 실패했다면 이유가 나옵니다. 성공했다면 발신 주소가 Amazon에서 승인되지 않았을 가능성이 큽니다.
업로드할 때 잘못된 메타데이터가 들어갔어요.
책 페이지의 온라인 메타데이터로 다시 검색하거나 편집으로 직접 고치세요.
표지가 없어요.
정보 누락 보기에 표지나 소개가 없는 책이 나옵니다. 온라인 메타데이터나 편집(표지 업로드)으로 해결할 수 있습니다.
리더에서 책이 열리지 않습니다.
EPUB과 PDF가 아닌 형식은 먼저 변환됩니다. 변환에 실패하면 리더에 표시되지만 책 다운로드는 여전히 가능합니다. 원인은 작업 페이지에서 확인할 수 있습니다.
태블릿에서 페이지를 탭해도 넘어가지 않습니다.
스크롤 모드에서는 탭하면 막대만 나타나거나 숨겨집니다. Aa에서 페이지로 바꾸세요. 링크를 탭하거나 텍스트를 선택한 상태에서도 넘어가지 않습니다.
