快速入门

Shelfy 是家用电子书库：上传图书后，Shelfy 会检查文件并在线补全元数据，之后家里的每个人都可以浏览、下载图书或发送到 Kindle。

  1. 上传 – 把图书拖到上传页面。
  2. 审核 – 检查完成后，核对建议的元数据，再把图书加入书库。
  3. Kindle – 在我的账户中填写 Kindle 邮箱地址，即可一键发送图书。

上传图书

  • 在上传页面，把文件拖进虚线框，或点击“从电脑中选择”。可以一次上传多个文件。
  • 支持的格式：EPUB、MOBI、AZW3、AZW、PRC、PDF、FB2、CBZ、CBR、DOCX、ODT、RTF、TXT、DJVU。
  • 监视文件夹：如果安装时已设置，复制到该文件夹（含子文件夹）的电子书会被自动导入。其他文件（图片等）不受影响；导入后的图书会被移出该文件夹。
  • 上传需要上传权限，由管理员授予。

检查与审核

每个上传的文件都会自动检查。检查日志会逐步显示结果：

  • 格式、完整性 – 文件是否与扩展名一致，是否完好？
  • 相同文件、重复 – 书库中是否已有完全相同的文件，或书名和作者相同的图书？
  • 内嵌元数据、封面 – 从文件中读取到了哪些信息，内嵌封面有多大。
  • 在线查询 – 已启用的在线来源给出的结果及匹配度（见设置 → 在线来源）。
  • 分类 – 根据标签和简介给出的建议。

在审核页面：

  • 从匹配结果中选出正确的一项（或“仅文件元数据”）。如果都不对，在重新搜索中用书名、作者或 ISBN 缩小范围。
  • 添加前可以编辑建议的元数据。封面可在内嵌封面和在线封面之间选择。
  • 分类会作为标签添加到图书，点击即可开关。
  • 如果已有这本书，“作为 … 格式添加”会把文件作为新格式附加到现有图书。
  • 如果有多个上传等待审核，它们都会列在顶部，“添加并继续下一本”会直接跳到下一本。
  • 队列中的全部批准会一次性添加所有匹配良好的图书（跳过重复）。

导入大量图书时，请打开设置 → 匹配可靠时自动添加：匹配度不低于 85% 且不重复的图书会自动添加。

浏览书库

  • 搜索 – 顶部搜索框可搜索书名、作者、系列、标签和 ISBN。
  • 视图 – 左侧菜单：全部、最近添加、热门、评分最高、按阅读状态；在浏览下：作者、系列、标签、出版社、语言、格式、评分。
  • 排序 – 在图书上方的栏中选择（添加时间、书名、作者、出版时间、系列、评分）。你的选择会被记住。
  • 网格和列表 – 用右上角的图标切换。列表会在封面旁显示主要信息和简介开头。
  • 大小 – 滑块调整封面大小（也就是每行显示几本书）;旁边可以选择每页显示多少本。
  • 快捷菜单 – 在网格视图中把鼠标移到封面上，即可下载、发送到 Kindle、编辑或加入书架。
  • 书架 – 在图书页面把任意图书放进个人书架（例如“假期”）;你的书架会显示在左侧菜单中。

图书页面

  • 下载 – 可下载任何已有格式。如果缺少 MOBI、AZW3 或 EPUB,Shelfy 会在下载时生成。
  • 转换 – 为图书永久添加一种新格式（需要编辑权限）。
  • 编辑 – 所有字段，包括封面。
  • 在线元数据 – 重新搜索在线来源；当前值和在线值并排显示，勾选要采用的项即可。
  • 阅读状态 – 未读、在读、已读；每个用户各自独立。
  • 历史记录 – 谁在何时下载、发送或编辑了这本书（编辑可见）。

在浏览器中阅读

在书籍页面点按阅读，书会直接在浏览器中打开——电脑、平板或手机均可。Shelfy 会为每位用户记住阅读位置：按钮会变为带百分比的继续阅读，在另一台设备上也能从同一位置接着读。

  • EPUB 直接打开。MOBI、AZW3 等格式在首次打开时会转换为 EPUB（几秒钟，可在任务中查看）。PDF 在浏览器自带的 PDF 查看器中打开。
  • 阅读需要下载权限；未登录的访客不能阅读。

翻页

  • 点按或点击页面右侧向后翻页，点按左侧约三分之一处向前翻页——和电子书阅读器一样。
  • 点按顶部区域可显示或隐藏上下工具栏，只留下正文。
  • 也可以左右滑动，或使用键盘的方向键、空格键和 Page Up/Down。
  • 底部的滑块可跳到书中任意位置；≡ 按钮打开目录。

文字设置（Aa）

  • 背景：浅色、护眼或深色。
  • 字号、字体（与书中一致、Literata、Georgia、特别易读的 Atkinson Hyperlegible，或简洁的无衬线字体）、行距、页边距。
  • 对齐（两端对齐或左对齐）、断字开/关。
  • 版式：宽屏时（如横放的平板）双栏或始终单栏；翻页或连续滚动。

设置按设备分别保存，因此手机和平板可以有不同的外观。

阅读进度

页面下方的一行显示当前位置。点按可在以下内容间切换：百分比、本章剩余时间、全书剩余时间、本章内页码。Shelfy 会学习你的阅读速度，读几页后时间估算就会变得准确。读到结尾时，这本书会标记为已读。

书签、划线、笔记

  • 书签：顶部的书签图标标记当前页（再次点按即删除）。
  • 划线：选中文字（触摸屏上：长按后拖动选择手柄），然后选择颜色。还可以在这里添加笔记。
  • 点按已有的划线可更改颜色、编辑笔记或删除。
  • ≡ 面板在不同标签页中列出书签和划线；点按即可跳转。

书签、划线和笔记保存在服务器上你的账户中，因此在所有设备上都能看到。

在平板和手机上，建议把 Shelfy 添加到主屏幕（见Kindle → 在手机上）：这样阅读器会全屏打开，没有浏览器的工具栏——就像电子书应用一样。阅读时需要能连接到 Shelfy。

Kindle

通过邮件发送

  1. 在我的账户中填写 Kindle 邮箱地址(…@kindle.com)。
  2. 在 Amazon 账户中，把发件地址添加到已认可的发件人(管理我的内容和设备 → 首选项 → 个人文档设置)。
  3. 在图书页面或快捷菜单中点击发送到 Kindle。

管理员会设置一个共享发送账户，但每个人也可以在“我的账户”中添加自己的账户（那里有 Gmail 设置帮助）。如果一本书只有 MOBI 或 AZW3 格式，Shelfy 会先生成 EPUB，因为 Amazon 现在只接受 EPUB。最大文件大小为 50 MB。

从 Kindle 浏览器下载

在 Kindle 上打开时，Shelfy 会自动显示适合墨水屏的简洁 Kindle 视图。在设置中选择较新的 Kindle(AZW3)或旧款 Kindle（仅 MOBI）。旧款 Kindle 请使用局域网地址(http://…)，因为旧浏览器无法打开很多 HTTPS 网站。

在手机上

在手机和平板上，左侧菜单会收起：用左上角的 ☰ 按钮打开（外观、语言和帮助也在其中）。在浏览器菜单中选择“添加到主屏幕”后，Shelfy 会以自己的图标作为独立应用打开——在 iPhone 和 iPad 的 Safari 中：分享 → 添加到主屏幕。在手机和平板上，Shelfy 也会在一个小窗口中主动提示；之后可在 ☰ 菜单的“安装为应用”中找到。

我的账户

  • 显示名称、界面语言、Kindle 邮箱地址、修改密码。
  • 个人邮件发送(SMTP)– 留空则使用共享账户。
  • 我的活动 – 你自己的下载、发送和上传记录。
  • 语言和外观（自动 / 浅色 / 深色）可在顶部栏中设置；在手机和平板上位于 ☰ 菜单中。

管理员须知

  • 用户 – 角色：管理员（完全访问）、编辑、读者；权限（上传、编辑、下载、删除）也可以逐项设置。还可以在这里为某人设置个人邮件。
  • 设置 – 左侧菜单中的独立项目；详见设置一节。
  • 语言 – 所有文字都可翻译；可以查看各语言的完成度并添加新语言。在界面中编辑的翻译在更新后依然保留。
  • 活动日志 – 所有重要事件及其时间：上传、添加、发送（包括失败）、下载、登录、设置更改。可按类型、用户和时间段筛选，或只显示错误。
  • 隐藏书籍 – 在书籍页面点按隐藏后，只有管理员能看到这本书：其他用户和访客在任何地方（列表、搜索、浏览、Kindle 视图）都看不到它，也无法打开其页面和文件。管理员会看到带标记的隐藏书籍，并可在左侧菜单的隐藏的书中找到；点按取消隐藏即可恢复。

忘记密码

管理员可以在“用户”页面重置用户密码。如果管理员忘记了自己的密码，请在服务器上运行：

docker exec -it shelfy python -m app.reset_password <用户名>

设置

面向管理员：左侧菜单中的设置。更改立即生效，无需重启。

常规

  • 默认语言 – 访客和新用户的界面语言；分类标签也以该语言添加到书籍。每个人仍可选择自己的语言。
  • 在线元数据查询 – 上传时和在书籍页面是否查询在线来源。
  • 监视导入文件夹 – 关闭后暂停监视，例如在整理文件夹时。（文件夹本身在安装时指定。）
  • 匹配可靠时自动添加 – 匹配度至少 85% 且不是重复的书，无需审核即可加入书库。

访问

允许无需登录即可浏览 – 没有账户的访客也可以浏览书库、搜索并打开书籍页面。下载、阅读、发送到 Kindle、书架以及任何修改仍需登录。

在线来源

Shelfy 在哪些数据库中查找书籍，以及按什么优先顺序：

  • Google Books – 全球、多语言；简介和封面。对中文书通常是最好的来源。
  • Open Library – 免费的全球书目；适合较旧的书和英文书。
  • Moly.hu（匈牙利）、DNB（德国）、BnF（法国）、Biblioteka Narodowa（波兰）、NDL（日本） – 各国的国家图书馆或书目库，适合在该国出版的书。

勾选要使用的来源，并用箭头调整顺序。Shelfy 会同时查询所有来源，并按匹配度排序结果；如果两个结果差不多好，列表中靠前的来源优先。推荐设置按钮会设置适合默认语言的列表。

没有自己的密钥时，Google Books 使用一个很小的共享配额，经常用完（检查报告中显示“HTTP 429”）。在 Google Cloud 控制台免费申请一个 Google Books API 密钥即可解决；密钥会加密保存。

邮件

用于发送到 Kindle 的共享邮件账户（SMTP），附测试邮件功能。

备份、恢复、迁移

Shelfy 由两部分组成：

  • 数据库(数据文件夹中的 shelfy.db):图书元数据、用户、书架、阅读状态、活动日志、设置 – 很小，只有几 MB;
  • 书库文件夹：作者/书名 (id)/ 文件夹中的图书文件和封面 – 占大部分空间。数据库指向这些文件。

两者合起来才是完整的书库。在管理 → 备份中：

  • 仅数据库 – 一个小 ZIP。如果书库文件夹在 NAS 上，且 NAS 自身的备份（如备份到其他存储卷或云端）已覆盖它，这就够了。
  • 完整备份 – 数据库 + 所有图书文件和封面，打包成一个 ZIP（100 本书约 100 MB）。可一次迁移整个 Shelfy。
  • 自动备份 – 每天把数据库备份到数据文件夹中的 backups 文件夹；可选择保留多少天。

迁移到另一台设备

  1. 在旧的 Shelfy 中下载完整备份。
  2. 在新位置启动 Shelfy，并创建一个临时管理员账户。
  3. 管理 → 备份 → 恢复：上传 ZIP。数据库和图书文件会恢复到位，原来的用户可以用自己的密码登录。

也可以把书库文件夹复制到 NAS 上的新位置，然后只恢复数据库备份。之后检查书库会列出缺少的文件。

大型书库请使用命令行

docker exec shelfy python -m app.backup create --full      # 完整备份到 backups 文件夹
docker exec shelfy python -m app.backup check              # 查找缺少的文件
docker compose stop shelfy
docker compose run --rm shelfy python -m app.backup restore /data/backups/<文件>.zip
docker compose start shelfy

备份包含密码哈希和加密密钥，请妥善保管。恢复前，Shelfy 总会先保存当前状态(before-restore-…zip)。

后台任务

较长的操作（检查上传、转换、发送到 Kindle、备份、恢复）可以在任务页面查看：谁启动的、当前状态、运行时长和结果。侧边栏会显示正在运行的任务数。管理员可以在这里启动书库检查（查找缺少的文件）和重复查找。任务会在列表中保留 14 天。

常见问题

图书没有到达我的 Kindle。
查看活动日志（管理员）或我的活动：如果发送失败，那里会显示原因。如果发送成功，很可能是发件地址未在 Amazon 中认可。
上传时采用了错误的元数据。
在图书页面用在线元数据重新搜索，或用编辑手动修改。
缺少封面。
信息不全视图会列出没有封面或简介的图书；可以用在线元数据或编辑（上传封面）解决。
书在阅读器中打不开。
EPUB 和 PDF 以外的格式需要先转换——如果转换失败，阅读器会提示，但仍可下载这本书。原因可在任务页面查看。
在平板上点按页面不翻页。
在滚动模式下，点按只会显示/隐藏工具栏——请在 Aa 中切换为翻页。点按链接或选中文字时也不会翻页。
